ICONIC FACES — VS CODE SETUP

1. Open this folder in VS Code.
2. Open index.html with Live Server (recommended) or another local web server.
3. Hover/click a character name.
4. Each character's MP4 is used as the full-screen background video.
5. The audio track INSIDE that MP4 is used as the character audio.
6. Click "Character Audio Off" to enable sound. This is intentional because browsers commonly block autoplay with sound until the user interacts with the page.
